# Personal Project Showcase App

A modern React portfolio application for displaying, adding, and searching projects. The app uses a clean responsive layout with Tailwind CSS styling, light green accents, and subtle purple highlights.

## Features

- Landing page with a list of projects
- Form for adding new projects dynamically
- Live search for filtering projects
- Responsive design for desktop and mobile screens
- Tailwind CSS styling

## Tech Stack

- React
- Vite
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
cd my-react-app
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173/
```
